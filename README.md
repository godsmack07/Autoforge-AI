# 🤖 AutoForge AI: Build AI Models Without Code

AutoForge AI is an end-to-end, user-friendly platform designed to empower everyone—from data enthusiasts to business professionals—to build, test, and deploy machine learning models through a stunning, intuitive interface. No coding required.

---

## 🚀 Key Features

### 1. 📤 Intelligent Data Upload
- Supports various dataset formats (CSV, TSV, etc.).
- Real-time data validation and preview.
- Integrated sample datasets for quick experimentation.

### 2. 🧹 Automated Data Cleaning
- Smart handling of missing values.
- Automatic duplicate removal.
- Real-time data analysis and cleaning statistics.
- Visual confirmation of data quality.

### 3. 🧠 Assisted Model Training
- Choose from various regression and classification algorithms (Random Forest, Linear Regression, etc.).
- Automated train/test split management.
- Real-time training progress and performance estimation.

### 4. 🧪 Comprehensive Model Tester
- **Interactive Visualizations**: Actual vs. Predicted scatter plots, accuracy over time, error distribution, and feature importance.
- **Deterministic Live Prediction**: Test your model with proprietary input fields and get instant, consistent results.
- **Export Capabilities**: Download test results and performance metrics for documentation.

### 5. 🚀 Seamless Deployment
- One-click deployment to REST API endpoints.
- Integrated Usage Examples (Python, JavaScript, cURL).
- Model export functionality (.pkl, .onnx, etc.).
- Live monitoring and deployment status tracking.

## 🛠️ Tech Stack

### Frontend
- **React.js**: Modern component-based architecture.
- **Vanilla CSS**: Custom, high-performance styling with premium glassmorphism effects.
- **Recharts**: Advanced data visualization and interactive charts.
- **React Icons**: Professional, consistent iconography.
- **React Hot Toast**: Real-time user notifications.

### Machine Learning (ML Engine)
- **Python**: Core logic and data processing.
- **Scikit-learn**: Industry-standard ML algorithms.
- **Pandas/NumPy**: Heavy-duty data manipulation.
- **FastAPI**: (Ready for integration) High-performance backend API.

## 📦 Installation & Setup

### Prerequisites
- Node.js (v16+)
- Python (3.9+)

### 1. Clone the Repository
```bash
git clone https://github.com/afrdbaig7/autoforge-ai.git
cd autoforge-ai
```

### 2. Frontend Setup
```bash
cd autoforge-ai/frontend
npm install
npm run dev
```

### 3. ML Engine Setup
```bash
cd ../ml-engine
pip install -r requirements.txt
python main.py
```
